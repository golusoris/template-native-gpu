# Support

## How to get help

- **Usage questions / design discussion** → GitHub Discussions.
- **Bug reports** → open an issue with the bug template (include version,
  backend, a reproducer, and your environment).
- **Feature requests** → open an issue with the feature template.
- **Security issues** → DO NOT open a public issue. Follow
  [SECURITY.md](SECURITY.md).

## Before filing

- Read [docs/development/build.md](docs/development/build.md) and the relevant
  `AGENTS.md` for the area you are touching.
- Search existing issues / discussions.
- For GPU-backend issues, note which backend (CUDA / HIP / Metal / SYCL /
  Vulkan) and confirm whether the CPU path reproduces.

## Commercial / SLA support

This is a community-maintained template. There is no commercial SLA. Downstream
products built from it may offer their own support channels.
